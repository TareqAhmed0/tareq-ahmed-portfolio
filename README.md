# Tareq Ahmed — Cyber Security Portfolio

A modern, responsive single-page portfolio website created for **Tareq Ahmed**, a Cyber Security professional. The website uses a dark hacker/SOC-terminal-inspired design with neon green and cyan accents.

> **Disclaimer:** This portfolio was created as a fun personal project for learning, experimentation, and showcasing design ideas. It is not intended to be a perfect or final professional portfolio, and some information may be placeholder or incomplete.

## Features

- Terminal-style animated hero section
- About section with profile statistics
- Categorized cyber security skills
- Certifications and learning roadmap
- Six featured project cards
- Education timeline
- Contact information and message form
- Fully responsive layout
- Custom dark cyber security aesthetic

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Custom CSS

## Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/tareq-ahmed-portfolio.git
cd tareq-ahmed-portfolio
```

Install the dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Create a production build:

```bash
pnpm build
```

Replace `YOUR_USERNAME` with your GitHub username.
